# Aggiornare Wikipedia e le mappe

> **In breve**
> Una volta l'anno (o ogni 6 mesi) scarica le nuove versioni dei file ZIM e delle mappe. **Sostituisci** i vecchi file mantenendo lo stesso nome e controlla che tutto si apra.

## Passo per passo

1. Segna sul calendario una data fissa, per esempio insieme al [controllo del kit di emergenza](../01%20Preparazione/Manutenzione%20del%20kit.md).
2. Scarica i nuovi file come spiegato in [Scaricare Wikipedia e le altre raccolte](Scaricare%20Wikipedia%20e%20le%20altre%20raccolte.md) e in [Installare le mappe offline sul PC](Installare%20le%20mappe%20offline%20sul%20PC.md).
3. **Prima** di cancellare i vecchi, apri i nuovi e verifica che funzionino.
4. Rinomina i nuovi file con lo stesso nome dei vecchi (per esempio `wikipedia_it.zim`) e cancella i vecchi.
5. Aggiorna il file `VERSIONI.txt` nella cartella `project-racoon-dati` con la data e il nome originale dei nuovi file.
6. Sul telefono: apri l'app delle mappe → **Scarica mappe** → **Aggiorna tutto**.
7. Se tieni una copia su chiavetta o disco esterno, aggiorna anche quella.

## Errori da evitare

- Cancellare i vecchi file prima di aver controllato i nuovi.
- Aggiornare proprio durante un'emergenza: si fa con calma, in tempi normali.
